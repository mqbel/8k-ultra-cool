# 8K Ultra Cool — موقع تسويقي

صفحة واحدة (HTML + CSS + JS مضمّنة) لعلامة **8K Ultra Cool** لأفلام التظليل الحراري.

## الأقسام
- هيرو بسكرول متدرّج من البرتقالي إلى التركوازي
- سلايد "صنع في السعودية" (مفرّغ أبيض)
- سلايد شعار العلامة
- المزايا
- جدول المواصفات: نانو تيتانيوم ونانو سيراميك — أربع درجات لكل سلسلة (شفاف · 00 · 01 · 02)
- مواصفات الرولة وأسعارها
- تواصل

## التشغيل محلياً
```bash
python3 -m http.server 8000
# http://localhost:8000
```

## الملفات
- `index.html` — الموقع كامل
- `assets/fonts/Doran-*.ttf` — خطوط العلامة
- `assets/img/` — الشعار الأصلي وشعار صنع في السعودية
